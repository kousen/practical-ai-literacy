# Freshmen talk · recording cue sheet

Segment targets for the recorded makeup video. Laptop only, in segments, in
Descript. **Cold-start Claude and the Pet every take. Never show the Outlook
inbox on camera.** [Full script](demo-script-freshmen.md) · slide notes in
`slides-freshmen.md` are the per-slide text.

## 0:00 · Intro + opening (slides 1–2)

To-camera intro (~30 s), then:
“These tools can help with difficult things and make surprising mistakes on
easy ones. I want to show you how both happen.”

Predictive AI picks an existing song; generative AI produces a response.

## 0:45 · Tokens (slides 3–4)

**Live (`platform.openai.com/tokenizer`) OR screenshot.** Words, word parts, punctuation.
Point to “Collge” (`Coll` + `ge`), the period, and “Let's” (one token in GPT-5.x, split in GPT-4).

**“Please pass the…”** — two clicks, real GPT-2 XL numbers, full bar = 10%.
Click 1: no context → *word, following, message* — it reads “pass” as pass **along**.
Click 2: after “We sat down to dinner.” → *salt, wine, bread*. Nothing looked up; context changed the fit.
Top guess under one in ten. One token at a time.

### “Fluent is not the same as verified.”

## 2:00 · Music and Pet (slides 5–6)

“Watch what changes when I ask a follow-up.”

**30-second clip. Bach: 1722. Gounod: composed 1852, published 1853.**
*(Aside: coding agent checked the YouTube page — no Content ID block, home
pandemic recording, "published 1853" in her description.)*

Click Play on the slide. **Pause before switching to the Pet.**

- “Was this a common practice?”
- “Did Gounod do this with other pieces?”
- “Was Bach a common source?”
- **“What evidence supports that?”**
- **“What haven't I asked you about?”** — pick one direction.
- Meta: “Is this a good way to use a tool like you? What should I watch out for?”

Interrupt naturally. Follow the conversation.

**Debrief:** “Did he do that elsewhere?” Context gives “he” and “that” meaning.

## 7:30 · What it does well (slides 7–13)

**A conversation, not a search box.** Bring it your context; ask for an
interpretation. (Google line spoken only.)
**Three asks** (clicks): “What haven't I asked?” · “Give me ten more” · “What can you do with this?”
Cover → reveal ram. “I used Nano Banana.”
**Start with the part you don't want to do.** “I didn't want to type my semester in. So I didn't.”
**The model is the engine. The app is the car.**
**A chat says; an agent does. Doing should ask.**
File for review: it prepares, I check, I import.

## 10:00 · My actual fall semester (slide 14)

**Cold-start Claude. Email permission = ASK.**
Say it before step 5: **academic-calendar PDF + schedule screenshot = no
class on break days. A search box can't do that.**

1. Find the Trinity Hartford academic calendar.
2. Paste `demo-assets/portal-course-schedule.png`; list meetings + no-class dates.
3. Check one meeting, one exclusion (Labor Day).
4. Export the .ics (prompt in the script); show one previewed event.
5. **“Email that .ics file to my Trinity address.”** → it asks → point at
   chip 5: **“Steps 1–4 were saying. This is doing.”** Approve ONCE.
   “Remember that moment.” **Cut before the inbox.**
   (No prompt? Download the file and say so.)

“The file is ready. It hasn't changed Outlook. I review it, then import.”

## 21:30 · Verify (slides 23–26)

**One claim → source → passage.**

**“Never let your schooling interfere with your education.”**
Usually attributed to Hartford's own Mark Twain.
Click: actually **Grant Allen (1894)** — pinned on Twain in a **1907 Daisy Air Rifle ad**
([Quote Investigator](https://quoteinvestigator.com/2010/09/25/schooling-vs-education/) /
[Center for Mark Twain Studies](https://marktwainstudies.com/the-apocryphal-twain-never-let-schooling-interfere-with-your-education/)).

“Can you explain how the evidence supports it?”

## 24:00 · Using AI for learning (slides 27–28)

**Schooling vs. education:** use AI to follow your curiosity, not bypass the work.
**Completing the task is not learning from the task.**
“Quiz me.” “Give me a hint, not the answer.” “Challenge this.”
Every course sets its own policy — check first, disclose, own what you submit.
Faculty skepticism is warranted; they're working it out in real time.
